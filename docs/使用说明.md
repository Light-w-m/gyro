# 三轴角度 · 纯黑横屏版

1. 将项目 `release/` 中的 `三轴角度-v1.1.apk` 发到安卓手机，下载后打开安装。可覆盖安装 v1.0。
2. 打开“三轴角度”，自动读取 X、Y、Z 三轴角度。
3. 点击任意一轴，自动切换为横屏全屏大字。
4. 再点一下屏幕，或按系统返回键，恢复竖屏三轴。
5. 测量前可长按屏幕超过 0.7 秒，松手后将手机保持静止 2 秒。出现“校准完成 · Z 已归零”后开始旋转；检测到明显移动或数据中断会取消这次校准。

界面为纯黑背景、白色数字；不需要浏览器、网络或登录。未收到传感器读数时显示 `—.—`。

这是安卓 APK，适用于 Android 6.0 及以上；Windows EXE 无法直接安装在安卓手机上。屏幕横向显示时，X/Y/Z 仍对应手机本身的物理轴。

Z 是相对于本次打开/校准方向的角度，范围 0～360°，不是指南针方向。退到后台后停止采样，再次进入前台会从当前方向重新开始。

“慢转优化”表示启用了未校准陀螺仪及固定零偏积分；“标准陀螺仪”“兼容姿态模式”表示设备使用了降级路径。校准只在手动长按后执行，正常慢转时不会自动把转动学成零偏。校准时必须真的静止，恒定慢转与零偏无法仅凭陀螺仪可靠区分。

无磁场参考的相对 yaw 长时间使用仍可能漂移，温度变化后可重新静置校准。接近 X=±90° 时欧拉角存在固有奇异性，测量平面转向建议将手机平放。

安装包已完成编译、签名校验、角度换算及合成传感器回放测试；当前没有连接真实华为手机，真机慢转精度及显示效果尚未验证。
