# v1.1 · yaw 慢转优化

## 问题与处理

v1.0 直接显示系统旋转矢量换算的 yaw，应用无法控制厂商融合算法的动态零偏估计和航向修正。用户反馈华为安卓手机慢速转动时 Z 读数错误；目前没有连接该手机，不能据此认定某个机型或固件的具体缺陷。

v1.1 为有陀螺仪的设备增加独立四元数积分：

- 优先使用 Android 未校准陀螺仪，初始化时保存一次系统零偏估计，正常测量期间不跟随其后续变化，不设置角速度死区。
- 使用传感器自身的纳秒时间戳和梯形积分，请求 100 Hz、零批处理延迟。超过 250 ms 的采样空洞不外推，避免把旧角速度延伸至整个中断期间；空洞期间的真实转动无法恢复。
- 优先使用游戏旋转矢量提供重力方向，缺失时使用普通旋转矢量；只提取重力来缓慢校正倾斜，不使用系统 yaw 对积分结果回拉。
- 每次进入前台以当前方向为 Z=0°，暂停后清除积分时间，不累计后台间隔。
- 长按屏幕超过 0.7 秒后松手，静止 2 秒可重新估计三轴零偏并将 Z 归零。明显运动、噪声过大、采样不足或数据空洞会拒绝校准；校准失败保留旧零偏。恒定慢转与零偏不能只靠惯性数据区分，校准期间必须静止。
- 优先路径注册失败或 2 秒无有效数据时，尝试标准陀螺仪，再降级为系统姿态模式；游戏旋转矢量无数据时尝试普通旋转矢量。主数据源中断时清空旧数字，并显示状态。
- 检查非有限值、无效四元数、短数据包、重复/乱序时间戳；兼容三分量旋转矢量、四元数归一化及 q/-q 符号变化。

包名仍是 `cn.local.axisview`，版本号 1.1、versionCode 2，与 v1.0 同证书签名，支持覆盖升级。原有三轴界面和轻触轴横屏放大方式保留。

## 官方资料与推断边界

1. [Android：运动传感器与未校准陀螺仪](https://developer.android.com/develop/sensors-and-location/sensors/sensors_motion)：未校准角速度保留工厂校准及温度补偿，另外提供零偏估计；系统在线校准会影响自行融合的连续性。这是采用固定零偏积分的依据，并不能单独证明用户手机的根因。
2. [Android：游戏旋转矢量](https://developer.android.com/develop/sensors-and-location/sensors/sensors_position)：游戏旋转矢量不依赖磁场，但允许 yaw 随陀螺仪漂移，不能视作长期绝对方向。
3. [AOSP：传感器类型](https://source.android.com/docs/core/interaction/sensors/sensor-types)：传感器坐标固定在设备自然方向；未校准陀螺仪和融合传感器的定义支持上述数据源分工。
4. [华为：陀螺仪热门问题](https://consumer.huawei.com/cn/support/content/zh-cn15593495/)：确认陀螺仪由应用调用，无需系统开关。该资料没有给出“慢转 yaw 错误”的通用固件结论或软件补丁，故本版没有加入未经证实的品牌/机型判断。

## 验证

- 原有 10,270 组角度换算往返测试。
- 新增合成传感器回放：±0.01～1°/秒持续慢转、7 种倾角、系统 yaw 停滞/跳变、系统零偏估计变化、采样间隔抖动、连续三圈、平滑反转、无效数据、采样空洞、前后台重置、校准和降级切换。
- Java 8 兼容编译、DEX 生成、APK 对齐、v1/v2/v3 签名验证；新旧证书及包名比对。
- 本机 ADB 没有连接设备，未完成真实华为手机慢转、温漂、安装及触摸显示实测。合成测试证明实现对这些输入的处理，不代表硬件精度保证。

## 已知限制

未使用磁力计/视觉等绝对方向参考，因此固定零偏随温度、时间变化仍会造成漂移；标准陀螺仪降级路径仍可能受到系统动态校准影响，纯系统姿态降级路径也不具备独立慢转积分。固定零偏不会恢复 HAL 本身已丢失的原始运动。欧拉角接近 X=±90° 时依然有数学奇异性，平面 yaw 测量建议手机平放。

安装包为 `release/三轴角度-v1.1.apk`；哈希及本次检查结果随包保存在 `release/`。交付目录只保留最新 APK，不添加功能描述后缀；后续构建在新包验证成功后自动清理旧包。
