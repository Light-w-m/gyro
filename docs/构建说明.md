# 构建与测试

## 所需工具

- JDK，当前包使用 JDK 24 编译，并生成 Java 8 兼容字节码。
- Android SDK Build Tools 35.0.0。
- Android API 35 的 `android.jar`。
- PowerShell。

项目使用 Android 原生 Java 和 SDK 命令行工具，没有 Gradle 或第三方依赖。

## 构建 APK

在项目根目录打开 PowerShell，按本机安装位置填写路径：

```powershell
$jdkPath = 'D:\java'
$buildToolsPath = 'D:\Android\Sdk\build-tools\35.0.0'
$androidJar = 'D:\Android\Sdk\platforms\android-35\android.jar'
$signingFile = 'D:\private-signing\axis-local.jks'
$signingAlias = 'axis-local'

New-Item -ItemType Directory -Force -Path '.\release' | Out-Null
$secret = Read-Host '签名密码' -AsSecureString
$env:AXIS_KEYSTORE_PASSWORD = [System.Net.NetworkCredential]::new('', $secret).Password
try {
    .\android\build.ps1 `
        -JdkPath $jdkPath `
        -BuildToolsPath $buildToolsPath `
        -AndroidJar $androidJar `
        -KeyStore $signingFile `
        -KeyAlias $signingAlias `
        -OutputApk (Join-Path $PWD 'release\三轴角度-v1.0.apk')
} finally {
    Remove-Item Env:AXIS_KEYSTORE_PASSWORD -ErrorAction SilentlyContinue
}
```

以上路径为示例，需要替换为真实路径。脚本会依次编译资源、编译 Java、生成 DEX、对齐 APK、签名并验证签名。

签名文件保存在项目目录之外，不包含在本交付包中。当前工作区原签名文件保留在 `work/signing/axis-local.jks`；生成后续覆盖升级安装包时应继续使用原签名，避免与已安装版本冲突。

## 运行角度换算测试

在项目根目录运行：

```powershell
$jdkPath = 'D:\java' # 修改为本机 JDK 路径
$testOut = Join-Path $PWD 'android\test-build'
New-Item -ItemType Directory -Force -Path $testOut | Out-Null

& (Join-Path $jdkPath 'bin\javac.exe') --release 8 -encoding UTF-8 `
    -d $testOut `
    '.\android\src\cn\local\axisview\AngleMath.java' `
    '.\android\tests\AngleMathTest.java'
if ($LASTEXITCODE -ne 0) { throw '测试编译失败' }

& (Join-Path $jdkPath 'bin\java.exe') -cp $testOut cn.local.axisview.AngleMathTest
if ($LASTEXITCODE -ne 0) { throw '角度换算测试失败' }
```

测试包括 10,270 组旋转矩阵往返转换、角度范围、奇异姿态、负零、Z 轴循环和缺失数据，不需要手机。

## 打包范围

`android/build/` 和 `android/test-build/` 是中间文件，不提交源码仓库。`release/` 是本地交付目录，APK 可以另外作为 GitHub Release 附件发布。`.apk.idsig` 是增量安装签名辅助文件，普通手动安装和下载发布只需要 APK 本体。
