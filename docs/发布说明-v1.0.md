# v1.0 · 本地打包版

## 功能

- 纯黑背景、白色数字。
- 自动读取 X、Y、Z 三轴姿态角，保留一位小数。
- 三轴竖屏上下平分；点任意一轴进入横屏全屏显示。
- 再点屏幕或按系统返回键恢复三轴。
- 无需网络、登录或浏览器。
- 前台屏幕常亮，后台停止传感器监听。

## 文件

- `三轴角度-v1.0.apk`：当时发布的安卓安装包，已由最新版替换，不再保留在交付目录。
- `release/SHA256SUMS.txt`：安装包 SHA-256 校验值。

## 验证状态

已完成编译、APK 签名校验和角度换算测试；尚未进行真实手机传感器与屏幕实测。若在 GitHub 发布供别人测试，建议将此版本标记为预发布版本，并保留此说明。

## 发布方式

Git 提交只包含项目源码和文档，`release/` 已被忽略。需要分发安装包时，在 GitHub 新建对应版本的 Release，并将 APK 和校验文件作为附件上传；不发布 Release 也不影响源码提交。
