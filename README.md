# 三轴角度

安卓手机三轴姿态角度工具：纯黑背景、白色数字。打开后自动读取传感器，三轴上下平分屏幕；点任意一轴进入横屏大字显示，再点屏幕或使用系统返回键恢复三轴。

支持 Android 6.0（API 23）及以上，不需要网络、浏览器或账户登录。前台保持屏幕常亮，退到后台停止读取传感器。当前安装包版本为 1.1，针对缓慢转动时的 yaw（Z 轴）读数增加独立积分处理。

## 直接安装

将 `release/三轴角度-v1.1.apk` 发送到安卓手机后打开安装。与 v1.0 使用相同包名及签名，可覆盖升级。

交付目录只保留最新版本的 APK，命名固定为 `三轴角度-v版本号.apk`，不添加功能描述等后缀。构建脚本在新包签名验证成功后清理旧包并更新校验值。

详细操作见 [使用说明](docs/使用说明.md)。

## 三轴含义

| 轴 | 含义 | 范围 |
| --- | --- | --- |
| X | 前后倾斜 | −180° 到 180° |
| Y | 左右倾斜 | −90° 到 90° |
| Z | 平面转向 | 0° 到 360° |

优先读取 `TYPE_GYROSCOPE_UNCALIBRATED`，以固定零偏和传感器纳秒时间戳进行四元数积分；系统旋转矢量只校正倾斜，不回灌其 yaw，避免动态零偏校正或系统航向停滞影响慢转。没有未校准陀螺仪时回退标准陀螺仪，再回退系统姿态模式。请求 100 Hz、关闭批量延迟，不设置角速度死区。

每次进入前台时，Z 从当前方向的 0° 开始。长按屏幕超过 0.7 秒，松手后静置 2 秒，可校准零偏并将 Z 归零。运动过程中不会自动学习零偏。界面显示“慢转优化”时启用了优先路径，其他传感器路径会显示相应状态。

横屏只改变显示方向，三轴仍对应手机的物理轴。Z 不是罗盘航向；无磁场/视觉等外部参考时，长时间测量仍可能漂移，温度变化后可以重新静置校准。欧拉角在接近 X=±90° 等奇异姿态时仍可能出现表示跳变；未收到数据或主数据源中断超过 2 秒时显示 `—.—`。
