# 手机三轴角度

`index.html` 是完整的单文件页面，包含 HTML、CSS 和 JavaScript，无需安装依赖。

## 使用

1. 用手机浏览器访问页面的 HTTPS 地址。
2. 点击“启用传感器”，允许浏览器访问运动与方向传感器。
3. 实时查看 X、Y、Z 三轴角度，单位为度，保留一位小数。
4. 点击任意一轴放大到全屏，再点该轴或“返回三轴”恢复。

竖屏上下平分三块，横屏左右平分三块。未收到的读数显示 `—.—`，不显示模拟数据。页面只在本机处理角度，不上传传感器数据。

## 三轴含义

| 显示 | 浏览器字段 | 含义 | 原始范围 |
| --- | --- | --- | --- |
| X | `event.beta` | 前后倾斜 | −180° 到 180° |
| Y | `event.gamma` | 左右倾斜 | −90° 到 90° |
| Z | `event.alpha` | 平面转向 | 0° 到 360° |

这里读取的是浏览器融合后的姿态角，使用 `deviceorientation` 事件；原始陀螺仪通常提供的是角速度。Z 轴的参考方向由设备和浏览器决定，不保证是正北方向。横竖屏切换时，显示布局变化，手机物理轴不重新映射。

## 自己部署

将 HTML 重命名为 `index.html`，放到任意支持 HTTPS 的静态网站空间即可。手机通过普通 `http://电脑局域网IP` 访问通常不能使用传感器，直接在文件管理器里预览 HTML 也不可靠。优先在手机 Safari 或 Chrome 中访问 HTTPS 页面。

支持系统全屏的浏览器会尝试隐藏浏览器界面；其他浏览器会让单轴铺满网页可视区域。iPhone 如需隐藏地址栏，可使用 Safari 的“添加到主屏幕”后从主屏幕打开。

参考：[浏览器姿态传感器说明](https://developer.mozilla.org/en-US/docs/Web/API/Device_orientation_events/Detecting_device_orientation)。
